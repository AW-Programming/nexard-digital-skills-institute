## 🔄 Content Update Guide

To update website content:

1. **Course Information**: Edit `src/components/Courses.jsx`
2. **Features**: Edit `src/components/Features.jsx`
3. **Contact Info**: Edit `src/components/Contact.jsx` and `src/components/Footer.jsx`
4. **Special Offers**: Edit `src/components/Hero.jsx` and `src/components/CTA.jsx`
5. **Phone Numbers**: Update in all components (search for "0726")

After making changes:
```bash
npm run build
```

Then redeploy to your hosting platform.
